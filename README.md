# Pixabay Image Search

Search and browse photos from Pixabay with infinite pagination and lightbox
preview.

## Features

- Search photos by keyword via [Pixabay API](https://pixabay.com/api/docs/)
- Paginated results — 15 images per page, load more on demand
- Lightbox preview on image click
- End-of-collection notification

## Stack

- Vite, JavaScript (ES modules)
- Axios, SimpleLightbox, iziToast

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
